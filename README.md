# CleanTrack

AI-powered public waste collection monitoring system.

## Problem
Public bins overflow, collection routes are fixed, and citizens cannot track whether action was taken.

## Solution
- Citizens report waste with a geotagged photo
- AI verifies the report and rates its severity
- Urgent spots get an optimized collection route
- Before and after photos prove cleanup on a public dashboard

## Planned Tech Stack
React, FastAPI, Supabase, OpenStreetMap, Google OR-Tools

## Status
Idea stage. Development will happen during the Resurrect hackathon.
